# Egypt Nutrition Coach

موقع تجربة لمحركات تخطيط الأكل والتمارين والمتابعة، مع الاحتفاظ بواجهة الأونبوردينج الحالية. محركات TypeScript-compatible JavaScript مستقلة عن التخزين وبدون استدعاءات AI أثناء الاستخدام.

نسخة التجربة: https://egypt-nutrition-coach-trial.bolddog32.chatgpt.site

## التشغيل

يتطلب Node.js 22 أو أحدث وPython 3 فقط لإعادة استيراد مكتبة التمارين.

```sh
npm ci
npm run build
npm test
npm run dev
```

المعاينة المحلية: `http://127.0.0.1:8787`. للاختبار المحلي، أرسل `oai-authenticated-user-id` بهوية اختبار إلى الـAPI. الاستضافة تضيف هوية المستخدم؛ هذه ليست آلية تسجيل الدخول النهائية للموبايل.

```sh
npx playwright install chromium
node scripts/browser-smoke.mjs
```

## الموجود

- خطط أكل إقليمية تحترم الميزانية والاستبعادات، وتستخدم سرعة الهدف بدون إضافة سعرات التمرين مرتين.
- تسجيل الوجبات المخططة بنصف الحصة أو غيرها، والأصناف بالجرام، والوجبات اليدوية، وإغلاق اليوم بعد اكتماله.
- بدائل وجبات تحت نفس قيود النظام، ونسخ خطط محفوظة منفصلة عن الأكل الفعلي.
- 868 تمرينًا من OpenExerciseDB مع العضلات والمعدات والشرح الإنجليزي وتراخيص كل سجل.
- تقسيمات الجسم كله، علوي/سفلي، دفع/سحب/أرجل، وعضلة في اليوم عند كفاية الأيام، مع مراعاة الوقت والمعدات.
- تسجيل المجموعات والأوزان والتكرارات وRIR، والجلسات المكتملة والفائتة ومدة الجلسة وRPE.
- متابعة النوم والإجهاد والضغط ووجع العضلات حسب المنطقة وألم الحركة والمرض، وخط أساس من متابعات المستخدم.
- مراجعة تفسر قرار الاحتفاظ بالخطة أو اقتراح تخفيف مؤقت أو تعديل سعرات أو زيادة مجموعات أو تثبيت الوزن.
- اقتراح نقل جلسة إلى يوم راحة مع اعتماد المستخدم، دون مضاعفة الجلسة في نفس الأسبوع.
- D1 للحفظ، معاملات ومراجعات متفائلة ومنع تكرار الطلبات، أرشيف خطط أكل وتمارين، وسجل تغييرات للمزامنة.

تفاصيل التشغيل والقرارات وحدود النسخة في [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md)، وعقد الواجهة في [docs/API.md](docs/API.md).

## المصدر والتراخيص

بيانات التمارين المشتقة: [OpenExerciseDB](https://github.com/rfivesix/OpenExerciseDB)، ترخيص CC BY-SA 4.0 مع الاحتفاظ بتراخيص ونسب السجلات الأصلية داخل `data/exercises.json`. النسخة المثبتة `202610112340`، بلا صور أو فيديو. الوصف وحالة ترجمة المصدر لا يمثلان مراجعة بشرية من فريق التطبيق.

```sh
python scripts/import-exercises.py
```

يتوقف الاستيراد إذا اختلف SHA-256 المثبت؛ تحديث المصدر يحتاج مراجعة وإعادة تثبيت البصمة.
