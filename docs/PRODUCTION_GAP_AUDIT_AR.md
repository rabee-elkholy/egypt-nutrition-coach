## 3. ملخص نتائج مصفوفة السيناريوهات النهائية (`E01`–`E16`)

جميع السيناريوهات الـ16 موثقة ومختبرة آليًا داخل [tests/e2e-release-scenarios.test.mjs](../tests/e2e-release-scenarios.test.mjs) وتعمل بنجاح بنسبة **100% (16/16 Pass)**:

1. **E01:** جلسة ويب مجهولة (`anon:...`) ← تسجيل دخول KMM موثّق ← دمج البيانات بموافقة صريحة مرة واحدة فقط، مع منع انتحال الهوية عبر الهيدر.
2. **E02:** تسجيل دخول على جهازين A وB ← إبطال جلسة الجهاز A عبر `/v1/auth/revoke` ← رفض A بـ`401` واستمرار عمل B، ومنع قراءة خطط حساب آخر (IDOR `404`).
3. **E03:** تعديل وحذف نفس الوجبة بين جهازين أوفلاين ← توليد `upsert` و`delete` tombstone في `/v1/sync/changes` وإرجاع `409 REVISION_CONFLICT` مع `mergeHints`.
4. **E04:** انقطاع الشبكة بعد تسجيل الماء وإعادة المحاولة 5 مرات بترتيب مفاتيح JSON مختلف ← سجل واحد فقط وإيصال متطابق (`Idempotency-Replayed: true`).
5. **E05:** البحث العربي عن (`كشري`، `ملوخية`، `محشي`، `كنافة`، `طعمية`، `عيش بلدي`، `شاي بسكر`، `قهوة بلبن`، `عصير مانجا`) ← نتائج دقيقة مصنفة المصدر والاعتماد مع حارس الكثافة للمشروبات.
6. **E06:** حجب الأمراض غير المدعومة (`diabetes`)، وإلزام الصوديوم المرجعي في `hypertension` (`0` قيم `null`)، واستبعاد الألبان في `lactose_intolerance` والفول/الطعمية في `favism`، وإزالة أي ادعاء مراجعة بشرية.
7. **E07:** خفض حجم استجابة البداية (`/v1/bootstrap`) إلى **3.1 KB** وإيصال تسجيل الماء إلى **413 B**، مع جلب تفاصيل يوم واحد عند الطلب (`/v1/plans/{id}/days/{date}`).
8. **E08:** تسجيل بيانات شهر كامل (30 يوم وزن وماء) واسترجاعها عبر صفحات مرتبة زمنيًا (`/v1/weight-logs?limit=10&offset=0`).
9. **E09:** انتقال المستخدم من `Africa/Cairo` إلى `Asia/Riyadh` قرب منتصف الليل ← احترام التاريخ المحلي لكل منطقة زمنية دون تكرار أو ضياع السجلات.
10. **E10:** معدات منزلية محدودة + إصابات متعددة + جلسة 20 دقيقة ← جلسة آمنة ضمن الوقت دون أي تمرين محظور.
11. **E11:** رفض مقترح تكيّف ثم إعادة تحميل الحالة ← بقاء الخطة الأصلية نشطة وحفظ النسخة دون تغيير قسري.
12. **E12:** تصدير بيانات الحساب (`/v1/account/export`) ثم حذفه (`/v1/account/delete`) ← مسح جميع الجداول ورفض أي محاولة مزامنة لاحقة بالتوكن القديم (`401 ACCOUNT_DELETED`).
13. **E13:** ترحيل سجل حساب قديم لمدة سنة كاملة (365 يوم وزن وماء ووجبات) عبر `/v1/account/backfill` ← تطابق تام في الأعداد والهويات (`365/365`) بدون فقد بيانات.
