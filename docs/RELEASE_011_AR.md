# إصدار 0.11 — تثبيت القرارات والمتابعة

هذا الإصدار يعالج نتائج مراجعة `327a99e`. لا يثبت جاهزية إطلاق طبي أو تجاري شامل.

## التغييرات

- استبعاد التمارين حسب نمط الحركة مع قواعد أسماء مكملة؛ لا يعود المحرك إلى قائمة غير مفلترة عند غياب بديل. نفس الفلتر مستخدم في التوليد والبدائل. هذه قواعد احترازية تحتاج مراجعة مختص، وليست وصفة تأهيل أو تصريحًا طبيًا.
- فحص الخطط القديمة دون تغيير تاريخها: التحذير من التمارين المستبعدة، إزالة زيادات الحمل المقترحة، وتعطيل التوصيات المعلقة حتى التصحيح. يمكن تسجيل نشاط حدث فعلًا دون اقتراح زيادة.
- تأكيد تسجيل كل الأكل إجراء مستقل عن الالتزام بالسعرات. تسجيل الوجبات أو بلوغ نسبة من السعرات لا يغلق اليوم. إضافة أو حذف تسجيل يلغي التأكيد السابق.
- إعادة فتح الأيام التفصيلية القديمة ذات التأكيد غير الموثق؛ الاحتفاظ بالسجل ووسم التأكيد القديم. لا يمكن معرفة ما إذا كان التأكيد القديم يدويًا أو تلقائيًا، لذلك يعاد طلبه احترازيًا.
- DASH يعتمد الصوديوم المرجعي فقط؛ القيم المجهولة لا تصبح صفرًا. التقديرات التحريرية القديمة ليست مصدر اعتماد للقيد. الخطط القديمة غير القابلة للتحقق تظهر بتحذير؛ مراجعة السعرات تتوقف عند عدم تحقق خطة DASH الحالية.
- زر التأكيد ظاهر خارج تفاصيل إضافة الأكل. توضيح أن المتابعة آلية وليست مراجعة من مختص بشري.
- توليد وفحص أعداد المكونات والقوالب والملفات من البيانات الفعلية عبر `npm run data:manifest` و`npm run check`.
- GitHub Actions لتشغيل اختبارات الكود ومصفوفة التوليد؛ لا ينشر تلقائيًا ولا يحتوي أسرارًا.

## التحقق

اختبارات الانحدار في `tests/release-011.test.mjs` تشمل كل الإصابات المدعومة عبر مستويات ومواقع متعددة، والبدائل، ونفاد المرشحين، وصيغ أسماء التمارين، والتأكيد الصريح وإلغائه، وترقية البيانات القديمة، وصوديوم DASH المفقود أو غير الصالح أو فوق الحد.

اختبار المتصفح `node scripts/browser-release-011.mjs` يستعمل هوية اختبار محلية مع API وD1 محليين. يغطي تسجيل وجبة فوق نسبة 80%، عدم إغلاق اليوم، تأكيده، إعادة تحميله، حذف التسجيل وإلغاء التأكيد، على عرض 390 و1280 بكسل.

المصفوفة لا تختبر سلامة طبية ولا تمثل توزيع مستخدمين حقيقيًا. الاختيار المسبق لوجبات DASH يستبعد الصوديوم المجهول. المصفوفة النهائية: 2250 حالة تمرين بدون أخطاء التحقق، منها 1738 بتغطية جزئية؛ و330/333 محاولة غذاء ناجحة و3 مرفوضة للقيود، بدون مخالفة في الخطط الناتجة. لا تخفف القيود لإخفاء نقص البيانات.

## حدود الإصدار

تسجيل الدخول وKMM وOffline Sync والتخزين المنظم والإشعارات والتوقيت حسب المستخدم ومراجعة متخصصين للتمارين والوصفات المصرية ما زالت أعمالًا مستقلة. لا توجد هنا مراجعة بشرية لكل تمرين أو قيمة غذائية. ملف الفهرس الغذائي الكبير لم يُقسّم في هذا الإصدار.

لا تُعاد كتابة أرشيفات الخطط ولا قرارات تم قبولها سابقًا؛ يتم إبطال الأدلة الغامضة للتحليلات المستقبلية وإظهار مشكلات الخطة الحالية. حذف الحساب والاحتفاظ والنسخ الاحتياطي ما زالت مطلوبة قبل إطلاق تجاري.

## حالة التسليم

نجح `npm run check` بعدد 131 اختبارًا بدون فشل أو تخطي، ونجح اختبار تأكيد الأكل في المتصفح للموبايل والديسكتوب. يشمل اختبار HTTP/D1 حفظ التأكيد الجديد بعد إعادة فتح سجل قديم، وأولوية التنبيه الطبي العاجل على تحذير الخطة القديمة. جرت محاولة النشر على العامل المعتمد فقط؛ تعذر النشر لغياب CLOUDFLARE_API_TOKEN في بيئة التنفيذ. لا يوجد تغيير منشور للموقع من هذه الجولة. يلزم ربط صلاحية النشر بالبيئة ثم تشغيل `npm run deploy`.
